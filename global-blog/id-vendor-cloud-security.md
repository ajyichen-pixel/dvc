# Bagaimana Melindungi Dokumen Perusahaan Saat Dibagikan ke Vendor dan Cloud?

Kolaborasi modern membutuhkan dokumen keluar dari organisasi. Risiko muncul ketika kontrol keamanan berhenti setelah file berhasil dikirim.

## Transfer aman belum cukup

Setelah file diunduh, penerima dapat menyimpan salinan, meneruskan, mencetak atau tetap menggunakannya setelah proyek selesai.

## Lima kontrol utama

- Hak akses
- Masa berlaku
- Pencabutan
- Watermark
- Audit aktivitas

## Peran DLP

DLP membantu mengontrol bagaimana data keluar melalui browser, email, aplikasi, USB dan layanan cloud. Perlindungan dokumen melengkapi DLP dengan mempertahankan kontrol pada file itu sendiri.

## Cloud bukan berarti kehilangan kendali

Perusahaan dapat memisahkan lokasi penyimpanan dari hak penggunaan. Dokumen sensitif sebaiknya tetap memiliki aturan walaupun berpindah media penyimpanan atau dikirim ke mitra eksternal.

## DVC untuk kolaborasi eksternal yang lebih terkendali

DVC menggabungkan perlindungan dokumen, DLP, watermark, pencabutan hak dan audit untuk membantu perusahaan berbagi informasi penting tanpa sepenuhnya menyerahkan kendali.
